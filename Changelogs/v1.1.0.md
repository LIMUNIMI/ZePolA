## GUI
 - Parameter strips can be locked
 - Order of parameter strips can be changed by mouse-dragging
 - Changed buttons for **Out** and **1x** from a checkbox to a circular led-button
 - Changed IR plot to be a step-plot (was linear)
 - Slightly changed LED colours when off

## Filter Designer
 - Added digital biquad filter designer
 - Expanded ranges for many parameters
 - Cross-check for ripple magnitude in elliptical filters

## Auto-gain
 - Made gradient-ascent routine more reliable to return the maximum in the history, not the last value
 - Improved gradient-ascent routine performance to optionally use an early-stopping rule on the number of successive unsuccessful updates
